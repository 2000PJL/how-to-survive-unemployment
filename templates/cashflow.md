# 家庭现金流盘点模板

> 每月花15分钟填写。数值不要上传到公开 Issue 或 PR。

| 项目 | 金额（元） | 备注 |
|---|---:|---|
| 银行可用现金 |  | 不含锁定资产 |
| 近期必要还款 |  | 未来90天内应付 |
| 每月住房必要支出 |  | 房贷、房租、物业等 |
| 每月食物交通 |  | 必要部分 |
| 每月育儿与医疗 |  | 不应盲目砍掉必要保障 |
| 每月其他必要支出 |  | |
| 每月确定到手收入 |  | 不算承诺未付的订单 |

**静态现金安全期**：`max(0, 银行可用现金 - 近期必要还款) ÷ max(0.01, 每月必要支出合计 - 每月确定收入)`。

> 若每月确定收入不低于必要支出，不宜按这个除法预测“无限期安全”。你仍然需要留出突发医疗、设备维修、收入波动的应急资金。

每周复核：

- [ ] 有没有已到期或将到期的还款？
- [ ] 哪项必要支出超出预算？
- [ ] 有没有新到账的现金，而非只签了合同？
- [ ] 失业保险金是否实际到账，医保是否正常？
- [ ] 如果现金不足3个月，下一步收入安排是什么？
