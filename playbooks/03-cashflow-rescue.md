# SOP 03｜现金流断了：做一张未来13周的现金日历

普通「存款÷开销」容易高估安全期。**尤其当信用卡账单、房贷、孩子学费集中在一个月到期时。**先做13周实际日历，再看“静态月安全期”。

## 1. 先定一个计数口径，防止重复计算

- **期初现金：**可随时取出的银行现金及确定能在该周到账的资金；有锁定期的理财不要当现金。
- **每周现金流入：**已确定到账的工资尾款、补偿、失业金、已确认回款。尚未批准的失业金和口头商单放在「可能入账」列，不计基础情景。
- **每周现金流出：**每笔真实到期支出。同一笔房贷**只放一次**，不要又在月必要开销里算一遍，又从期初现金减一次。
- **期末余额：**`上周期末余额 + 本周确定流入 - 本周现金流出`。
- **底线：**预留不可动用的最低医疗与生活缓冲额，用来判断风险；不是可以安全花光的余额。

## 2. 五步填法

1. 记下今天银行账户能即时动用的人民币金额（家庭成员已同意的共同资金才能计入）。
2. 把未来13周的房贷、房租、信用卡、借款、医保、孩子固定费用记到**到期周**。
3. 把明确会到账的失业金/工资/尾款填到**预计到账周**；审批中款项不进入保守情景。
4. 每周滚动算余额，找出第一周低于预设缓冲线的时间。
5. 先做低成本行动：控制非必要支出、尽快催收合法欠款、优先恢复可验证收入、提前与债权机构合法协商困难。

## 3. 三个场景

- **保守：**失业金尚未核准，先按0；尚未收取补偿也先按0；只算已确定收入。
- **基准：**已批准、有具体发放日的收入计入预计入账周。
- **乐观：**潜在订单、未来Offer等只能单列，不据此安排固定大额支出。

**实例（纯假设）：**账户8万元，每月必要支出1万元，未来一个月还有一笔2万元的额外到期借款。粗略静态安全期取决于是否把该2万元已经包含在月开支中。**如果是额外的**，首月之后可用余额更低；如果已经包括在1万元内，不能重复减。

## 4. 风险信号和动作

| 发现 | 优先动作 | 验证完成 |
|---|---|---|
| 13周内有周末余额低于0 | 本周开始优先恢复收入、压缩可变费用、沟通债务方案 | 有经办/雇主/客户回复与下次复盘日 |
| 医保存在待遇空档 | 尽快咨询医保经办，不凭预测收入忽略保障 | 待遇起始日期明确 |
| 期末现金仍正但在下降 | 设每周30分钟滚动预算 | 连续两周保持台账 |
| 收入靠潜在订单预测 | 把预计回款改为0重跑保守情景 | 仍知道最差能扛多久 |

## 5. 每周家庭复盘议程（20分钟）

上周实际余额 → 未来两周到期款 → 医保/基本生活 → 求职和实际接单进展 → 哪一项开支/收入假设需要更新。

**完成标准：**有一份真实13周收支日历、最早预警周、明确下周动作。对高风险债务和财务法律问题，请咨询合格专业人员。
