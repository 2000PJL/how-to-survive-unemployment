# SOP 01｜收到裁员通知，当天怎么做？

**适用：**劳动合同中的员工收到裁撤、协商解除或不续签相关沟通。**不适用：**直接套算劳务合作、承揽或个体经营合同的补偿。

## 1. HR突然约谈，先问这6句话

1. “公司是希望协商解除，还是打算依法单方解除？依据是什么？”
2. “如为协商方案，解除日、经济补偿额、付款日分别是什么？”
3. “经济补偿使用的前12个月工资金额，包含哪些工资性收入？”
4. “奖金、提成、未休年假报酬和尚欠工资如何结算？”
5. “离职证明的解除原因、社保减员原因及最后缴纳月份是什么？”
6. “请发书面协议供我核对，我会在合理时间内回复。”

谈话涉及自身合法权益时可视情况依法留存事实记录。注意隐私及商业秘密保护。**不需要现场承诺同意，也不要口头威胁或冲动签署。**

## 2. 计算前先判断法律情形

| 问题 | 对应路径 | 要小心什么 |
|---|---|---|
| 双方协商解除？ | 看谁提出，协商条款及法定补偿要求 | 不以“双方签了字”推定一律N+1 |
| 法定特殊情形，按《劳动合同法》第40条解除？ | 核对提前30日书面通知或额外一个月工资 | “1”的工资口径一般是上个月工资，不自动与N相同 |
| 经济性裁员？ | 审核法定人数、情形、程序及经济补偿 | 别说经济性裁员自动N+1 |
| 违法解除？ | 结合证据评估继续履行/赔偿请求 | “2N”需要满足相关法律前提，不是喊价 |
| 合同期满不续签？ | 另看《劳动合同法》第44、46等条及续订情形 | 与单方裁员不同 |

**N的常见算法：**`工作年限对应月数 × 离职前12个月平均工资`；法定年限不足整年的折算、高工资封顶另看具体规则。**2N**是违法解除赔偿时可能适用的计算标准；**N+1**是部分第40条单方解除情形的实践说法，不能混同。

示例：3年8个月、前12个月月均工资15000元，且无高工资封顶情形，则**N=4×15000=60000元**。2N仅在符合违法解除赔偿条件时可能为120000元；不能默认所有情况拿到。

**法律特别保护：**有些人不适用一般的第40、41条解除路径，例如符合《劳动合同法》第42条规定的孕期、产期、哺乳期，医疗期及部分工伤情形等。收到通知应优先按自身情况核实，不能仅按N试算签署。

**红旗：**协议未写明金额、支付日期；要求填写不真实的“主动离职”；含模糊的“双方互不追究一切权利”却未厘清已知欠款；不提供个人合同和合法工资记录。

## 4. 受阻处理

- **公司要求当日签：**要求合理核对时间，把书面方案发给专业人士看。
- **金额算不清：**先收集劳动合同、工资个税、银行流水、工资明细等合法资料，标明缺口。
- **公司口头说违法解除也只能给N：**先核实解除程序和事实，再选择劳动仲裁等合法救济，不拿“2N”当必得价格。
- **办公电脑被锁：**通过个人官方账户查询社保个税记录，依法索取个人劳动证明，不拷公司机密。

**完成标准：**你有一份逐项补偿核对表、书面沟通/协议和支付时间表，知道下一步要签、谈还是咨询专业人士。

**政策：**[《中华人民共和国劳动合同法》（政府转载）](https://rsj.gz.gov.cn/zcfg/flfg/content/post_7993969.html)，特别核对第40、46、47、48、50、87条；劳动仲裁时效另依具体争议判断。
