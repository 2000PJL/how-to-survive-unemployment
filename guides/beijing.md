# 北京｜失业自救政策速查

> 最近核验：2026-10-08。仅适用于符合条件的个人，办理前仍须确认最新规定。

## 1. 失业保险金

北京现行标准自 2025-09-01 执行：

| 失业保险累计缴费 | 前12个月每月金额 |
|---|---:|
| 满1年不满5年 | ¥2,129 |
| 满5年不满10年 | ¥2,156 |
| 满10年不满15年 | ¥2,188 |
| 满15年不满20年 | ¥2,215 |
| 20年以上 | ¥2,286 |

领取第13个月起统一 ¥2,129/月。**领取月数以经办机构核定为准。**

办理：北京人社官方渠道或规定线下机构；先核实累计缴费、解除原因和失业登记。

- [北京市人社局：2025年发放标准（现行有效）](https://rsj.beijing.gov.cn/xxgk/2024zcwj/202507/t20250729_4161229.html)
- [北京市失业保险金申领发放实施办法](https://rsj.beijing.gov.cn/xxgk/2024zcwj/202412/t20241227_3974931.html)

## 2. 医保与灵活就业社保

符合规定正在领取失业金期间，职工医保费用按政策从失业保险基金支付。其他断缴/恢复规则，需按本人参保状态确认。

北京2026-09-16更新的**个人灵活就业参保指南**列出：本市户籍、法定劳动年龄内、没有在用人单位参保。**非京籍注册个体户并非自动取得个人参保资格**。不要虚构劳动关系挂靠社保。

- [北京灵活就业人员参保指南](https://www.beijing.gov.cn/fuwu/bmfw/bmzt/lhjyry/202507/t20250709_4145280.html)
- [灵活就业参保“一件事”官方入口](https://banshi.beijing.gov.cn/pubtask/bhyjs/lhjy/lhjy.html)

## 3. 离职公积金提取

符合条件的非北京户籍缴存人，离职后个人账户封存满半年且没有在异地继续缴存，可以申请销户提取；其他情形适用不同规定。

- [北京住房公积金管理中心：2026年操作详解](https://gjj.beijing.gov.cn/web/zwfw5/386727/386730/386732/11098664/index.html)

## 4. 顺风车注意事项

根据北京市交通委公布的《私人小客车合乘出行指导意见》，合乘强调真实顺路、非营利分摊成本，本人所有、京牌7座以下车辆等条件；每车每日不超过2次。开车前确认商业车险与责任险是否覆盖相关出行方式。

- [北京市交通委：合乘规定](https://jtw.beijing.gov.cn/xxgk/2024zcwj/gfxwj/202407/t20240716_3750809.html)
